# Frontend Spec

The frontend is an operational dashboard, not a marketing page.

Pages:

- Dashboard: core counts, benchmark story, demo navigation.
- Eligibility Verification: synthetic member/service coverage check.
- Claim Validation: claim selection, rule matches, code matches, risk, fixes, explanation.
- Rule Explorer: RAG payer rule search.
- Codebook Search: ICD/CPT/HCPCS search.
- Scaling Benchmarks: synthetic benchmark and scaling readiness.
